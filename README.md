# סל קניות – השוואת מחירים לפי סניף

אפליקציית Web בעברית שמשווה את מחיר סל הקניות שלך בין סניפי הסופרמרקטים הקרובים לבית, לפי **נתוני אמת** מקובצי שקיפות המחירים הרשמיים.

## איך זה עובד

```
GitHub Actions (כל 4 שעות)
  └─ collector/collect.py
       ├─ מוריד את קובץ הסניפים (Stores) של כל רשת
       ├─ ממקם כל סניף על המפה (OpenStreetMap Nominatim, עם מטמון ב-cache/)
       ├─ משאיר רק סניפים ברדיוס radius_km ממרכז האזור שב-config.json
       ├─ מוריד לכל סניף את PriceFull + PromoFull העדכניים
       └─ כותב JSON קומפקטי ל-_site/data/
GitHub Pages
  └─ site/ (HTML + JS, בלי שרת)
       ├─ ממקם את הכתובת שלך (Nominatim, בדפדפן בלבד)
       ├─ מסנן סניפים לפי הרדיוס שבחרת (1/2/3/5 ק"מ, מרחק אווירי)
       ├─ מתאים מוצרים: ברקוד זהה בין רשתות → "מדויק"; אחרת "חלופה" עם חישוב לפי מחיר ליחידה
       ├─ מחשב סלים, דירוג, חיסכון וקנייה מפוצלת
       └─ מציג סופרים נוספים מהמפה שאין עבורם נתוני מחירים
```

## עקרונות

* אין מחירים מומצאים. כל מחיר מגיע מקובץ שקיפות רשמי, ולידו מוצגים שם הקובץ ושעת העדכון.
* מוצר שלא נמצא מסומן "חסר מידע" ולא נכלל בסכום.
* חלופה בגודל שונה מחושבת לפי מחיר לגרם, למ"ל או ליחידה, ומסומנת בבירור. אם לא ניתן לחשב גודל, היא לא נכללת בסכום.
* רשת שלא נאספה מופיעה בטבלת הכיסוי, יחד עם הסיבה.
* מבצעים: בסכום נכללים רק מבצעי יחידה לכלל הלקוחות (אפשר לכבות). מבצעי כמות ומבצעי מועדון מוצגים כטקסט בלבד.
* הכתובת שלך נשמרת רק במכשיר שלך (localStorage), כמו גם הרשימות השמורות.

## מגבלות ידועות

* הפורטלים של **קרפור, ויקטורי, מחסני השוק, חצי חינם וח. כהן** עונים רק לכתובות IP מישראל, ושרתי GitHub נמצאים בחו"ל. כדי לכלול אותן, אפשר להגדיר secret בשם `ISRAEL_PROXY` (פרוקסי עם יציאה בישראל) או להריץ את האיסוף ממחשב בישראל.
* סופרים עצמאיים לא חייבים לפרסם מחירים, ולכן מוצגים רק כ"ללא נתוני מחירים".
* המרחק הוא מרחק אווירי ולא מרחק נסיעה.
* ירקות, פירות ובשר במשקל אין להם ברקוד אחיד, ולכן הם מותאמים לפי שם.

## הגדרות

`config.json`: מרכז האזור (`center`), רדיוס האיסוף (`radius_km`) ורשימת הרשתות.
הרצה ידנית: Actions → "עדכון מחירים ופרסום האתר" → Run workflow.

מקור הקוד לקריאת הפורטלים: [israeli-prices](https://github.com/rxradar/israeli-prices) (MIT).
